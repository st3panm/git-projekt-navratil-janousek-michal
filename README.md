# \- Základní aritmetické operace (sčítání, odčítání, násobení, dělení)

# 

# \## Návod k instalaci a spuštění

# 1\. Klonujte repozitář:

# &#x20;  git clone \[https://github.com/st3panm/git-projekt-navratil-janousek-michal.git](https://github.com/st3panm/git-projekt-navratil-janousek-michal.git)

# // Ukázka logiky výpočtu
